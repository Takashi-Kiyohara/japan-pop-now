### 1.4 Video pipeline (A + B both landed)

**A) GitHub Actions ffmpeg auto-extract** — `b571697`:

`.github/workflows/process-image-inbox.yml` now runs ffmpeg BEFORE the TypeScript pipeline. Extracts up to 10 keyframes per video (1 frame every 90 frames ≈ 3s at 30fps), names them `<base>__library_NN.jpg`, then deletes the original. The v4.2 pipeline processes the JPGs as normal library-mode images.

Supported extensions: `.mp4` `.mov` `.avi` `.m4v` (case insensitive).

Cost: ~0.5s per second of video, $0 per run (runs in GitHub Actions free tier).

**B) GDrive → Claude manual** — not yet implemented. This is done via a future shortcut: user drops a GDrive link in Cowork, Claude fetches the video via GDrive MCP, extracts frames locally, uploads to the inbox.

### 1.5 Filename `--[size]` suffix parsing

`parseFilenameV4` regex now accepts `body-top--wide`, `body-top--tall`, etc. Legacy `body-tall` as a position hint still works (deprecated but handled).

New `SizeHint = 'auto' | 'wide' | 'tall'` added to `ParsedFilename`. Downstream consumers can switch on `sizeHint` to choose crop ratio (16:9 vs 4:3 portrait-tolerant).

Code path: `splitPositionAndSize()` in `scripts__process-image-inbox_v4_2.ts`.
