### R-1 E 軸 ESL false positive 61.3%
Stanford 2023 + 2025 Turnitin: TOEFL ESL writer に AI 検出器 **61.3% false positive**。Takashi が Japanese-native で英語記事を書くため、ESL translation artifact (短文 / parallel structure) が AI fingerprint と誤分類、E 軸 systematic over-FAIL。MiniLM PAN 2011 plagiarism 確定帯は `0.65-0.92`、Draft 1 の `0.60` は false positive 領域。
**修正**:
- E 軸 = **3-feature composite** (em-dash + boilerplate + sentence-length variance)、Takashi 過去 confirmed-human article 5 本を **calibration baseline** にして個人 baseline 引算
- B 軸 cosine 0.60 → **0.72** (PAN mean+1.5σ)、TL;DR/FAQ 重複セクション除外 + n-gram overlap 補助
- ref: [Stanford ESL 61.3% FP](https://hastewire.com/blog/study-reveals-ai-detectors-false-positives-on-non-native-writers), [MiniLM PAN](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2)

### R-4 維持 ≥5 PASS が HCU site quality と矛盾
Surfer SEO 2024 study: HCU は **site quality, not content quality**、weakest article が site classifier を pull。≥5 PASS = 71%、weakest 30% 残置で「predominantly unhelpful」flag 解除不可。Surfer 推奨は **15 great > 50 okay**。
**修正**:
- 維持 threshold `≥5 PASS` → **`≥6 PASS かつ A,F,G 必須 PASS`** (firsthand + helpfulness + author binding = mandatory anchor)
- 修正 bucket は **publish 維持の noindex 隔離**、修正完了後手動 re-audit で 6 PASS 通過時のみ index 復活
- 88 → 維持 target を 6-18 から **10-15** に下方修正、削除を 50+ に上方修正
- AdSense reapply 前に「全 indexed = 6 PASS」CI gate
- ref: [Surfer HCU site quality](https://surferseo.com/blog/helpful-content-update-study/)

### B-2 press URL 不在 B 軸 null pass で削除誤判定
press URL 50%+ 不在で null = PASS なら B 軸 free pass で score 底上げ、削除すべき記事が修正に昇格。
**修正**:

- fallback 不能なら B null + IG check 必須

### B-7 CI gate 未整備 → leak loop
W5 で削除した article タイプを新規 PR で再生産する risk。
**修正**:

- 既存 indexed article も pre-AdSense reapply で全件 6 PASS verify

### B-1 `robots:noindex` skip 処理 (RED)
既存 noindex article も HCU `predominantly unhelpful` classifier の site-quality signal に寄与 (noindex でも crawl 対象)。Draft 2 で skip 廃止、noindex は「削除確定」として 410 候補化、または robots.txt Disallow で classifier 露出から外す。

### B-4 niche phrase 誤認 (YELLOW)
"collab cafe" "limited edition" "oshi-tabi" は japan-pop-now brand vocabulary、boilerplate と誤認すると E 軸 systematic FAIL。
**修正**: `lib/audit/niche-phrases.json` whitelist (20-30 phrase) を boilerplate regex から除外。

### B-5 410 化 GSC removal + CDN purge (GREEN if 言及)
Mueller: 410 first encounter で removal、ただし cache 4-12 週残存 = Cloudflare/CDN purge 必須。deploy script に `cdn purge + GSC URL Removal API call` ワンセット化。

### B-6 修正 bucket 残置の再 reject risk (RED)
threshold ギリギリ修正 (5-6 PASS) で AdSense reapply → HCU classifier が再度 unhelpful 判定する double-rejection cascade。修正は noindex 隔離 + 手動 re-audit 6 PASS 通過のみ復活。
