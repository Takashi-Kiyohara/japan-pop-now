## Methodology

Each article scanned for:

1. **Word count vs image floor.** Body stripped of frontmatter, fenced code blocks, inline code, and image markdown. Token count → floor: <800→2, 800-1499→4, 1500-2499→5, ≥2500→6 image references. Images counted as Markdown `![]()` or JSX `<ArticleImage>` / `<Image>` / `<Picture>` / `<FeaturedImage>`.
2. **Mojibake.** Search for `??` runs and known cp932-misdecoded UTF-8 patterns (`窶・`, `繝`, `縺`, `邨` series).
3. **Internal links.** Match `]( /articles/<slug>)` and `href="/articles/<slug>"` only (avoiding image path false positives), then verify each `<slug>` resolves to an existing non-deprecated article file.
4. **Affiliate URLs.** Hosts `klook.com|agoda.com|booking.com|getyourguide.com|viator.com|amazon.*` outside any `<AffiliateLink>` JSX block. Auto-fix only candidates: clean MDX with simple `[text](url)` patterns.
5. **Frontmatter integrity.** `title` ≤60 ch, `description` ≤155 ch + unique, `date`/`pubDate`, `category` in approved set, `featuredImage`, `featuredImageAlt`, `author == "Takapon"`. (BOM-tolerant parser.)
6. **AuthorBox + body byline.** First eight non-empty body lines scanned for `By Takapon` / `By 清原崇`. `清原崇` anywhere in file → P0.
