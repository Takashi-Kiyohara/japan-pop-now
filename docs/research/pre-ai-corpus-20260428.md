## Caveats

- All Atlas Obscura / National Geographic extracts are fair-use prose snippets, not full-article reproductions. Used only for statistical baseline computation, not for republishing.
- Wikivoyage CC BY-SA license preserved by recording the exact `oldid=` revision URL in the table; these revisions can be re-fetched at any time via the MediaWiki API.
- Files in `.tmp/pre-ai-corpus/` are gitignored (already excluded by the repo `.gitignore` for the `.tmp/` prefix). Only this source-list document is committed.
- Extraction pipeline used **no AI processing of source material**. All conversion was done by deterministic Python regex / `html.parser` / wikitext-strip scripts (`_parse_html.py`, `_parse_wikitext.py`). Raw HTML/wikitext was downloaded directly with `curl` against publisher origin or the Wayback Machine — no LLM in the loop. This is critical: the corpus must remain free of AI-paraphrasing artifacts to function as a clean human-baseline.
- Word counts computed with `wc -w`. Articles outside the 400–4,000 word window were rejected (per task spec; the underlying parser truncates at 2,800 words for very long Wikivoyage city guides to keep distribution roughly Gaussian).
- Geographic spread: Wikivoyage entries cover Asia, Europe, North/South America, Africa, Oceania, plus some thematic guides (Hokkaido, Kyushu, Surfing). Non-Wikivoyage entries are weighted toward Japan-relevant material (since this is the publication's domain) but include pieces on Sudan, Israel, Nevada, Tristan da Cunha, etc., to broaden style coverage.
- All Wayback snapshot dates fall between 2019-07 and 2022-11. Original publication dates of the blog posts themselves predate those snapshots, so the prose itself is firmly pre-2023.
